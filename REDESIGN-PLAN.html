参考网站分析 + 重设计方案

参考站：westandwillow.com（其 "Custom Embroidered Pet Clothing" 线即为本项目的直接竞品）
目标市场：United States · 语言 EN · 货币 USD · 视觉 Premium + Emotional + Minimal + Warm

A. 参考网站分析（West & Willow，基于实测）

该站是 Shopify 架构的 DTC 定制站，核心卖点 "Turn your pet photo into an illustrated pet portrait, custom-stitched onto apparel"。也就是说，它卖的正是我们要做的宠物照片 → 数字插画 → 刺绣到衣服。这是我们最有价值的对标对象。

① 网站结构（Sitemap）

  • / 首页（Hero + Best Sellers + 服装线 + UGC + How It Works + FAQ）
  • /pages/custom-pet-portraits 单/双/三宠肖像落地页
  • /pages/custom-pet-apparel 定制服装聚合页
  • /collections/* 集合页（如 jewelry-accessories）
  • /products/[slug] 产品页（带 Loox 评价、"Old $X → From $Y" 锚价）
  • /pages/reviews 评价墙 · /pages/best-sellers · /pages/image-guidelines
  • Footer 含 Shop / Help / About / Legal / Social / 邮件订阅

② 首页布局（从上到下，实测区块）

  1. Skip-to-content 可访问性链接 → 公告/导航
  2. Hero：大标题 "Custom Pet Portraits" + 主推产品卡（带 Loox 19,141 评价徽标）
  3. Best Seller 网格：3 列产品卡，划线价 Old $105 / From $77，Shop Now CTA，Loox 星标+评价数
  4. Custom Embroidered Pet Clothing 促销块（说明照片→插画→刺绣的逻辑）
  5. Featured Accessories 第二组网格（马克杯/抱枕/crewneck）
  6. West & Willow In The Wild：UGC 墙，带 Instagram @handle
  7. How It Works：3 步（选照片 → 定制 → 艺术家插画&发货）
  8. FAQ 折叠
  9. Footer

③ 产品展示方式

  • 卡片统一：正方形/竖向缩略图 + 标题 + Old Price $105.00 From $77.00 划线锚价 + Shop Now
  • 评价以 Loox 徽标呈现（星级 + 大数字，如 19,141 reviews），强社会证明
  • Best Seller 角标置于卡片左上

④ 定制流程（关键差异点）

West & Willow 的 How It Works 是 3 步：① 选宠物照片（"We accept 98% of all photos!" 降低上传焦虑）② 定制（加名字、背景色、风格、画框尺寸）③ 艺术家插画&发货。

重要：他们明确"不提供设计预览/proof"（"we do not offer artwork previews or proofs"）。这恰恰是我们可以差异化的地方——按你的要求提供诚实的版式预览（明确标注"示例版式·非最终成品"，不伪造 AI 结果）。

⑤ 图片比例 / ⑥ CTA / ⑦ 配色 / ⑧ 字体

  • 图片比例：产品卡竖向（约 4:5），Hero 大图 + 产品卡并置；UGC 方块 1:1
  • CTA：主按钮深色底 "Shop Now" / "Shop Best Sellers"，文案行动导向
  • 配色：暖米白背景 + 近黑文字 + 暖色调（出现 Walnut/Charcoal 画框背景描述），克制高级
  • 字体：展示标题用衬线（编辑感/高端），正文无衬线；大留白

⑨ 用户购买路径

Pet Photo 心智 → 选产品（肖像/服装）→ 定制选项 → 加购 → 结算。路径短，但预览缺失是信任断点。

⑩ 信任元素 / ⑪ FAQ / ⑫ 评论&UGC / ⑬ Footer / ⑭ 移动端

  • 信任：Loox 海量评价（19k+）、"接受 98% 照片"、30 分钟内可改单的响应式承诺
  • FAQ：照片指南（近景/光线/避免俯拍模糊）、多宠、可改单时限、为何无预览（坦诚说明）
  • 评论/UGC：星标+Verified Buyer 暗示、UGC "In The Wild" 带 @handle、Browse Reviews 入口
  • Footer：Shop / Help(Contact,FAQ,Shipping,Returns,Size Guide) / About(Story,How It Works) / Legal / Social / 邮件订阅
  • 移动端：Skip-to-content、单列堆叠、移动优先的卡片网格（推断，Shopify 主题默认响应式）

B. UX 优点 & CRO 优点（可借鉴）

UX 优点

  • 大留白 + 编辑式衬线标题，高级感强
  • 卡片信息密度低，决策成本低
  • UGC "In The Wild" 把客户当内容主角
  • How It Works 三步可视化，降低认知负荷

CRO 优点

  • 价格锚点：Old → From 制造划算感
  • 社会证明密度：Loox 大数字评价
  • 上传安抚："98% 照片可用" 消除顾虑
  • FAQ 前置：在决策前解答疑虑
  • 多入口 CTA：Hero / 网格 / 区块反复引导

D. 不应复制（合规红线）

以下一律不复制：Logo、品牌名 "West & Willow"、所有文案原文、产品图/插画/宠物照片、画框素材、页面源码、Loox 评价数据。我们仅借鉴其经过市场验证的结构与转化模式，全部内容自建。

E. 改进 / 差异化机会（我们的突破口）

  • 诚实预览：提供 "示例版式" 预览（非伪造 AI），填补竞品空白，提升信任
  • 宠物情绪叙事：强化 "Your pet is family / 纪念意义 / 礼物惊喜" 的情绪价值
  • 移动优先上传：大点击区、进度提示、即时本地预览
  • 配置集中化：品牌名/色/字体/图片全部抽到 config，便于换品牌/多品牌
  • 统一占位图系统：无真实图也不崩，比例统一防跳动

F6 · Mock / 接口策略（无 API Key 时的诚实处理）

  • 产品/评价：静态 mock 数据（lib/data/*），评价明确标 Demo / 示例评价，绝不伪造真实消费者
  • 购物车：客户端 Context + localStorage，无后端
  • 上传照片：纯前端 FileReader → object URL 本地预览，不上传服务器
  • 预览：诚实 "示例版式 · 非最终成品" 占位（可选叠加画框+名字文字），不伪装 AI 生成
  • 结算：Mock 表单 → 订单确认页；真实支付(Stripe/Shopify)待你提供 Key 后接入
缺失 API 不会阻塞建站。后续接入点已在 lib/api/client.ts 用 USE_MOCK 开关预留（products / upload / preview / orders）。
